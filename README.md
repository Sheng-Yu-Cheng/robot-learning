# Robot Learning

這是一個透過實作與實驗累積機器人學習知識的專案。將方法、模型、任務與實際執行的實驗放在一起，方便理解、重用及比較不同想法。

專案主要包含：

- **方法與演算法**：Actor-Critic、優勢估計等可重用邏輯。
- **模型與策略**：Diffusion Policy、Flow Matching Policy，以及相關網路架構。
- **任務與資料**：Gymnasium、ManiSkill 整合、示範資料與資料準備工具。
- **實驗**：將模型、資料和任務組合起來，進行訓練與評估。
- **環境設定**：記錄執行不同實驗所需的套件與環境。

不同方法與實驗可以採用適合自己的結構與執行方式。優先保留清楚、可執行的實作，再根據實際需要整理共用部分。
